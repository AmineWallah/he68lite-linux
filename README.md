# HE68Lite Linux
## About
**!! STILL IN VERY EARLY DEVELOPMENT, I AM NOT RESPONSIBLE FOR ANY KEYBOARDS FRYING AND HOUSES CATHCING FIRE !!**

Basic linux driver to interact with the Epomaker HE68 Lite keyboard considering there is no native driver for it out there
For now can only change the color of the LEDs by changing the script directly.

## Dependencies
You will need to install **python3** from the official website for Windows users, or your preferred package manager for everyone else.

Once that is done, you will also need **pyusb** for the script to be able to communicate with the keyboard.
